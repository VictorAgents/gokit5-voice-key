Gokit5 Voice Key开源 · Windows x64 · 测试版
让手边的四颗键，多做一点事

按住说话。
松手，回到手头的事。

把同款四键 Gokit5 改造成无线语音输入按钮，也是一块能自己定义的蓝牙小键盘。快捷键、开关机音效和彩色灯光，都能在电脑上设置。

下载 Windows 安装程序完整安装与使用说明
普通用户无需 Python 或 Arduino。仅支持已确认接线的四键 Wi-Fi 版，首次安装先做完整个人备份。

真实安装，分步看一遍

USB → 配网 → 蓝牙 → 控制台

真实同款设备操作录屏，经剪辑、等待加速和隐私遮挡。电脑已安装 VB-CABLE 的步骤明确显示自动跳过；具体实测边界见验证清单。

01 / 声音走 Wi-Fi

拿起设备，说话

设备麦克风把声音送到电脑。按住说话、松手停止；接收端未连接时可通过蓝牙右 Alt，改用电脑麦克风。

02 / 按键走蓝牙

四颗键，自己定义

点按或按住快捷键，加减组合短按也能配置。映射同步到设备后，蓝牙快捷键可以独立使用。

03 / 让它像你的设备

声音和颜色都可改

导入最长 6 秒的开关机音效，选择固定色、呼吸、彩虹或按键反馈，调整亮度与空闲熄灯。

第一次使用，先分清四件事

1. USB 数据线：备份、安装、更新

直连电脑、核对四键板与串口，工具读取两份完整 Flash 校验后才刷入。配置完成可拔线使用。

2. Wi-Fi：传设备麦克风的声音

在本地 USB 配网窗口输入 2.4GHz 网络信息。电脑和设备需在同一可互通局域网，密码不发到聊天。

3. 蓝牙：传快捷键

同时按住＋／－约 3 秒至灯闪，在 Windows 添加 Gokit5 Keys-xxxxxx。蓝牙配对成功不代表声音链路已完成。

4. 电脑：接收声音并交给输入法

向导检查虚拟麦克风，缺少时准备官方 VB-CABLE；按要求安装/重启。输入法需选对麦克风，并设置对应快捷键。
