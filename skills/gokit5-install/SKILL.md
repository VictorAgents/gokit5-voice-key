# Gokit5 安装助手

目标：让用户自己的 Agent 帮助完成安装，保留可恢复的本机备份，并通过实际按键和语音测试确认结果。本技能本身不授予刷写设备、安装驱动、重启电脑或发布私人数据的权限；沿用用户已明确授权的范围，不重复索要同一操作的许可。遵守所在 Agent 平台的工具权限和确认规则。

适配基线：Windows 10/11 x64，Gokit5 Voice Key **0.13.0-alpha.1**。这是非官方测试版。支持电源、麦克风、＋、－四键，已确认接线的 ESP32-S3 / 16MB Flash / 8MB PSRAM / ES8311 硬件；仅芯片名称或相似外壳不能证明兼容。

## 开始时做什么

1. 确认用户要做的是首次改装、已有本项目固件更新、配网/排障，还是恢复安装前快照。不要把更新或排障变成重新首次安装。
2. 只询问尚缺的信息：Windows x64、板型依据、USB数据线是否接好、目标语音软件；说明首次改装将替换原厂程序和云端功能。没有获得实际改装授权前，只做检测、下载和校验。
3. 先读随技能提供的[Windows 操作流程](references/windows-install.md)。它包含当前真实按钮、命令入口、下载校验、失败处理和恢复差异。仓库完整说明为 [README](https://github.com/VictorAgents/gokit5-voice-key#readme)，实测边界为 [RELEASE.json](https://github.com/VictorAgents/gokit5-voice-key/blob/v0.13.0-alpha.1/RELEASE.json)。使用其他版本时先核对该版本文档，不能直接套用旧界面或参数。

需要重启或换会话时，在本机留下简短接续记录：版本、任务模式、已完成阶段、备份清单位置和下一步，不记录密码/密钥。回来先复检当前状态；已经刷入的设备不要因为会话中断再次执行首次安装。

## 工具能力决定操作方式

- **有经过授权的 Windows 桌面工具**：按实时界面观察操作官方项目安装器；输入后重新读取状态，不靠旧坐标猜测成功。不要读取用户其他文档或关闭未保存窗口。
- **只有终端/文件工具**：完成下载校验、只读USB检查和程序自检，打开安装器，再逐步引导用户点击。当前版本没有正式的无界面安装、更新或恢复命令；不能声称已自动完成图形界面步骤。
- **没有本机工具**：提供本机操作指导和验收清单，不声称已检查设备或已刷机。
- 用户亲自处理 USB插拔、实体按键、Windows管理员确认/安全提示、蓝牙首次配对和语音测试；Wi-Fi密码只在本机配网窗口输入，不索取到聊天、命令行参数或日志。不能处理的界面按当前平台规则交给用户。

## 安装时必须保留的顺序

1. 从指定 GitHub Release 下载配套EXE和SHA256SUMS，先校验，再运行；普通用户不用装Python或Arduino。
2. 核对板型和目标USB端口，一次只接一台。停止旧接收端；旧控制台让用户保存并正常关闭。
3. 用安装器检测语音环境。CABLE Input播放端、CABLE Output录音端与格式都就绪才算可用；已装就跳过。缺少时按向导取得用户同意、准备独立官方驱动，由用户完成管理员确认和Install Driver。重启电脑前明确告知并等待用户准备好，重启后复检；不能把退出码0当作驱动已可用。
4. **首次安装**选择“一键备份并刷入”；**已有本项目固件更新**选择“已有本项目固件：备份并更新（保留配网、按键与音效）”。两者都必须先完成两份完整16MB读取、散列一致、芯片/容量/安全状态与身份检查、固件包校验。应用更新还要求现有分区一致，才仅写应用区。
5. 等明确显示完成。两份完整快照和清单保留在用户本机，并建议另存独立介质。备份一致只证明读取一致，不能称“恢复已验证”或“镜像一定为原厂”。
6. 用本机USB配网窗口设置2.4GHz Wi-Fi，等明确成功；电脑与设备处于可互通局域网。首次蓝牙由用户同时按住＋／－约3秒至灯闪，在Windows添加 **Gokit5 Keys-xxxxxx**。这两项顺序可以互换。
7. 打开控制台，启动接收，等设备已连接。麦克风设 **RightAlt / 按住说话**，保存并等同步；输入法语音快捷键和麦克风设置分别核对，设备声音应走 **CABLE Output**。
8. 用用户准备好的空白正文测试：按住设备麦克风键，听到就绪音结束后说通用测试句，松手停止并出现文字；再测试自定义蓝牙按键。最后拔USB仅电池再测，才记录无线实物验收。

用户明确只要蓝牙快捷键时，可跳过虚拟麦克风和设备语音验收，使用默认的离线蓝牙右Alt；首次更改映射仍需Wi-Fi接收端同步。不要为了完成完整语音流程而强迫用户安装其不需要的驱动。

## 不能省略的边界

- 不使用整片擦除、`--force`、eFuse写入、保护绕过或其他板型的BIN；也不直接调用底层工具绕过安装器的双备份/身份检查。
- 未识别板型、备份不完整或不一致、安全保护开启、设备身份变化、包校验失败时，停止刷写；分区不匹配时不能自动改用首次安装。
- 用户自己的原始快照只能恢复到原设备。恢复是单独任务，不能在排障时擅自执行；更新后的快照不是首次改装前快照。没有自己的原始备份时，不承诺回到原厂。
- 不上传 `devices/`、`backups/`、`logs/`、receiver.json、Wi-Fi输入截图、完整Flash或个人音频；它们可能含设备凭据。只记录必要的脱敏阶段结果。
- 就绪音代表电脑链路准备好，不保证云端识别一直在线。蓝牙配对不等于设备声音已进入电脑；离线右Alt备用改用电脑麦克风，输入法也要选到电脑麦克风。
- 不能自动修改防火墙、系统默认音频、其他启动项、证书信任或重启电脑来“修好”安装。用户要求的具体设置变更需按实际授权处理。

## 完成时交付给用户

说明所用版本、任务模式、备份清单的本机位置与校验结果、Wi-Fi/蓝牙/接收端状态，以及哪些项目由用户真实确认。按需说明控制台的快捷键、声音和灯光设置，见操作流程。

区分：下载/自检通过、刷写通过、启动联网通过、真实语音和电池验收、完整恢复验收。没有实体测试就写“待用户测试”；本版本完整恢复、全新Windows驱动安装/重启、Windows重启自启、长期稳定/续航和可信电池百分比仍有未验证项。
